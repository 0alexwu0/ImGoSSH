本版本恢复系统原生标题栏，并改进 Windows 窗口和终端输入法兼容性。

## 改动

- **恢复原生窗口**：撤回自绘标题栏、无边框缩放热区、标题栏配色及反复刷新原生框架的逻辑，针对 Win10 输入时整页抖动的问题。窗口按钮、拖动和缩放交由系统处理。
- **Win10 标题栏兼容性**：关闭 Windows 上应用主题到原生窗口的同步；启动时清除窗口库自动套用的深色样式，使用标准浅色原生标题栏。Win11 保留系统默认标题栏；应用内部 ImGo、Dark、Light 主题和终端配色继续保留。
- **输入法定位**：修正 egui-winit 实际接收的候选窗口区域，将排除区域从整个终端缩小至光标所在位置，使用终端输入目的标识。保留中文等非英文输入、SSH 连接后自动聚焦和中英文混排对齐。

## 下载与升级

提供 Windows x86-64、Linux x86-64、macOS Apple Silicon、macOS Intel 安装包及 `SHA256SUMS.txt`。每个包包含图形客户端、`igssh`、`igscp`、`igsftp`、使用文档和集成脚本。解压替换程序即可，已有配置与会话继续使用。

Linux 需要 glibc 2.35 或更新版本；macOS 程序未签名和公证。

## 验证与限制

本地 Windows 格式检查及 126 项测试通过，9 项需要额外环境的测试按条件跳过。回归覆盖连续终端输入的布局稳定性、主题切换与焦点变化、菜单打开关闭、窗口版本判断，以及 SSH 焦点和输入法提交、候选定位。

Win10 的标题栏点击、输入和高 DPI 显示仍需实机确认，以上自动化检查不代表所有 Win10 环境的抖动和绘制问题均已解决。
