本版本改进 SSH 终端的输入与显示，修正 Windows 10 标题栏主题及启动闪烁，并更新功能文档与截图。

## 新增与改进

- **连接后直接输入**：SSH shell 可接收输入后自动聚焦终端，切换终端标签页后恢复输入焦点；连接完成后不会持续抢占其他输入框的焦点。
- **非英文输入法**：支持中文、日文、韩文等输入法的预编辑与 UTF-8 提交。预编辑文字在本地显示，候选窗口跟随终端光标；确认、取消和切换候选时使用的按键不会误发到远端。普通文本输入和粘贴分别处理，保留终端的括号粘贴模式。
- **中英文混排对齐**：统一终端主字体与回退字体的文字基线，保持字符列位置，修正混合显示时文字上下错位。
- **Win10 主题标题栏**：创建窗口前选择跟随软件主题的标题栏，消除启动后由白色切换为深色时的闪烁；支持拖动、双击最大化、最小化、还原、关闭及边缘缩放。Win11 保留原生主题标题栏。
- **功能展示**：更新 README 和真实软件截图，展示多标签 SSH、SFTP 侧栏与独立双栏、反向工作区映射和外观设置。截图使用本地演示服务及示例数据，拍摄版本见截图说明。

## 下载与升级

提供 Windows x86-64、Linux x86-64、macOS Apple Silicon 和 macOS Intel 安装包，以及 `SHA256SUMS.txt` 校验值。每个安装包包含图形客户端、`igssh`、`igscp`、`igsftp`、文档、JumpServer 连接器和反向工作区辅助脚本。

解压后替换程序即可，已有会话与配置继续使用。Linux 需要 glibc 2.35 或更新版本；macOS 程序未签名和公证。

## 验证

本地 Windows 已通过格式检查、130 项测试及 Release 构建；9 项需要额外环境的测试按条件跳过。新增测试覆盖 shell 就绪时的焦点及首次输入、输入法预编辑与提交、候选按键隔离、UTF-8 字节发送、焦点丢失清理和候选窗口定位。

Win10 实际启动显示效果及系统输入法操作仍需实机确认。发布流程为四个平台构建安装包，对原生测试目标运行回归测试，并在 Windows 验证 JumpServer 连接器安装流程。
