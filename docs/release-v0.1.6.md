本版本修复终端右键菜单被窗口底部裁切、鼠标拖选时选区不能实时显示，以及 SFTP 上传文件夹时进度显示不准确的问题。

## 修复与改进

- **终端右键菜单**：在窗口底部或右侧打开菜单时，菜单会自动调整位置，确保全部菜单项可见。
- **终端实时选区**：按住鼠标拖动时，立即显示当前选中文字的高亮，支持反向拖选与跨行选择；松开鼠标后保留选区并按原有行为复制。
- **SFTP 文件夹上传进度**：文件夹中的每个文件分别列出大小、进度、速率与状态，并支持单独取消。进度列表可以滚动查看，完整传输记录保留在传输队列窗口。
- **目录结构**：上传时保留嵌套目录、空目录与空文件。文件逐个传输；目录读取失败会显示错误。

## 下载与运行

每个包均包含图形客户端 `imgossh`、命令行工具 `igssh` / `igscp` / `igsftp`，以及 `LICENSE` 和 `README.md`。

- Windows x86-64：解压后运行 `imgossh.exe`。
- Linux x86-64：需要 glibc 2.35 或更新版本，解压后运行 `imgossh`。
- macOS Apple Silicon / Intel：按处理器架构选择。程序未签名和公证，首次运行可在「系统设置 → 隐私与安全性」中允许打开，或执行 `xattr -dr com.apple.quarantine <解压目录>`。

## 验证

通过 `cargo fmt -- --check` 和 `cargo test --workspace --locked`。新增回归测试覆盖窗口边缘菜单、多层目录上传计划、各文件大小与空目录，以及鼠标按住时选区的实时更新与绘制。
