本版本新增会话文件密码加密、启动解锁和系统凭据库自动解锁，并优化密码设置界面。

## 新增与改进

- **会话文件加密**：可使用密码加密整个 `sessions.toml`，通过 PBKDF2-HMAC-SHA256（600,000 次迭代、随机盐）派生密钥，使用 AES-256-GCM 加密并校验完整性。
- **启动解锁**：启用加密后需要密码才能读取已保存的会话。暂不解锁时可以继续使用软件，新增会话仅保留在内存中，不会覆盖原文件，也不会提示重新设置密码。
- **自动解锁**：可选择将密码保存在 Windows 凭据管理器、macOS 钥匙串或 Linux Secret Service 中，下次启动自动解锁。密码不写入 `config.toml`，凭据标识经过混淆；系统凭据库不可用时可继续手动输入密码。
- **加密管理**：在“设置 → 管理加密与密码”中启用或关闭加密、修改密码及取消密码保存。修改密码或关闭加密需要验证当前密码。
- **首次使用与升级迁移**：新用户在首次新建会话并确认保存后选择是否加密；已有会话文件的用户升级后，启动时提示一次，设置密码后立即加密现有会话。
- **密码界面**：加宽对话框、增大输入框与按钮，提供启用加密滑动开关、状态说明、固定底部按钮和可滚动表单。未启用加密时明确提示服务器密码可能泄露。
- **数据保护**：错误密码、损坏或无法读取的会话文件不会被覆盖；加密保存采用原子替换，不产生明文临时文件。会话日志不再输出完整会话对象中的连接密码。

## 使用说明

请妥善保管加密密码，遗忘后无法恢复。自动解锁由当前操作系统账户保护；移动数据目录后需要重新保存自动解锁凭据。未解锁期间创建的临时会话不会在之后解锁时自动合并，解锁后恢复文件中的原会话列表，已打开的连接可继续使用。

## 下载与运行

每个包包含图形客户端 `imgossh`、命令行工具 `igssh` / `igscp` / `igsftp`，以及 `LICENSE` 和 `README.md`。

- Windows x86-64：解压后运行 `imgossh.exe`。
- Linux x86-64：需要 glibc 2.35 或更新版本；自动解锁还需要可用的 D-Bus / Secret Service 凭据库。
- macOS Apple Silicon / Intel：按处理器架构选择对应压缩包。程序未签名和公证。
