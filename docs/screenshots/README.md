# 软件截图

本组图片截取自当前源码构建的 ImGoSSH v0.2.3 Windows 应用，使用独立的 `IMGOSSH_HOME` 演示配置。

| 图片 | 展示内容 |
| --- | --- |
| `../gui.png` | SSH 终端、中文与英文彩色日志、SFTP 侧栏、会话分组、多标签与服务器状态 |
| `sftp.png` | 独立 SFTP 标签页，远程与本地双栏目录 |
| `workspace.png` | 多目录反向工作区映射、挂载选项和权限配置 |
| `appearance.png` | 语言、字号、行距、终端调色板和界面主题 |

截图中的 SSH / SFTP 连接来自仅监听 `127.0.0.1` 的本地演示服务；终端输出、服务器指标、账号与文件均为示例数据。工作区截图展示配置，不表示已完成 Linux sshfs 挂载。图片来自真实界面捕获，工作区与外观设置截图仅裁剪了周围区域，没有改写界面内容。

这些图片用于介绍产品功能，不作为 Win10 启动行为或真实生产服务连接的验证证据。
